# OpenClaw Discord Bot Extensions

.cario2weak (custom)

These only work with OpenClaw Discord Bots.

You cannot get carioCores or the cario3ngine on my website or my app, sorry.

With the CPE, you are able to use these plugins with bots that aren't openclaw, but it is limited. They won't be able to everything as it may not be capable.

Tell your bot to install like this: "Look through the file at this link: (file link from this repo) and apply it as a plugin."

To update files without going into repo, import CarioUpdater and use "!update" as an Owner/Primary, and select what to update.
